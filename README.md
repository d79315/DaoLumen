# DaoLumen

Provides customizable dashboards for DeFi applications that track swaps and liquidity pools in real-time.

With DaoLumen, you get a lightweight tool that stays out of your way.

**What you get**

- Provides customizable dashboards for DeFi
- applications that track swaps and
- liquidity pools in real-time

## Key Features

- Provides customizable dashboards for DeFi
- applications that track swaps and
- liquidity pools in real-time

## Technology Stack

- rust
- rust framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoLumen.git`
2. `cd DaoLumen`
3. Install in editable mode: `pip install -e .`

## Configuration

DaoLumen is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
